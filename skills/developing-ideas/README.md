# Develop Ideas

Develop Ideas turns an approved Design Brief into a chosen, fully described
solution. It establishes the measuring stick, develops meaningfully different
ideas, compares them using evidence and human judgment, and completes the Spec
needed to create the solution.

The phase entry point is [`$start-develop-ideas`](start-develop-ideas/SKILL.md).

## Criterion skills

1. [**B1 — Develop design specifications**](develop-design-specifications/SKILL.md)
   defines the justified, testable requirements used to judge possible
   solutions.
2. [**B2 — Develop feasible ideas**](develop-feasible-ideas/SKILL.md) creates and
   tests meaningfully different solution shapes before convergence.
3. [**B3 — Present and justify the chosen design**](present-and-justify-the-chosen-design/SKILL.md)
   compares the feasible ideas and records the human-approved choice.
4. [**B4 — Develop planning drawings and diagrams**](develop-planning-drawings-and-diagrams/SKILL.md)
   defines the models, contracts, flows, interfaces, and creation requirements
   needed to complete the Spec.

## Durable artifact

The developing-ideas document keeps the evidence and reasoning behind all four
criteria. Its sections use the exact criterion names above. The approved Spec is
the handoff to Create Solution. It contains the chosen solution and enough
planning detail to construct a logical implementation plan without inventing
missing design decisions.

## Movement

New Criterion B work normally begins with B1 and proceeds through B4. B2 protects
the work from anchoring on the first plausible idea. Focused prototypes answer a
named question and preserve their findings. Production work proceeds from the
human-approved design.

Work can return to Inquiry when an idea exposes a missing part of the need, move
to Evaluate when an artifact needs an evidence-based judgment, or revisit any
Criterion B decision when new evidence changes the design. Record each move in
`workflow-tracker.md`.
